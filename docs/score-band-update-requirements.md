# 更新版の点数帯変更（2026-10-20 承認された方針）

更新版に実装する。既存の星評価を維持し、その星に対応する新しい点数帯へ点数を移す。点数から星を付け直す変更ではない。現行本番へ直ちに適用する承認ではない。

|星|新点数帯|
|---|---|
|5|98〜100|
|4.5|93〜97|
|4|88〜92|
|3.5|82〜87|
|3|76〜81|
|2.5|70〜75|
|2|64〜69|
|1.5|59〜63|
|1|54〜58|
|0.5|51〜53および50以下|

51〜100の段階数は星5から3,5,5,6,6,6,6,5,5,3。点数帯の圧縮で別点が同点になることはユーザー了承済み。同点になっても以前の点数順と同点内順位を使い、作品の上下関係を保持する。未採点、星のみ、0点、レビュー、視聴履歴、ジャンル、シーズン評価、その他メタデータを保護する。

変換関数と安全な接続条件は `score-band-migration-design.md` に記録。帯の両端を対応させる単調変換を純粋処理として実装済み。0〜49点は維持し、旧50点は旧星1を維持するため新54点とする。アプリの保存・復元への接続はまだ実装していない。

旧版が新点数を旧閾値で解釈して星を変えるリスクがあるため、独立保存領域と識別付き取込を準備する。架空740作品と順位の境界例で変換処理を検証済み。バックアップの耐久保存、移行コミット、旧JSON復元、多タブ・同期との接続は次の作業。最新の正当な編集を固定された過去バックアップで上書きしない。

元のリファクタリングは第⑤のカード装飾比較から継続する。基準1c07c58、装飾診断はscripts/regression/card-decoration-probe.cjs。新点数帯の準備と混同して全体完了と報告しない。main・本番・実データの変更、マージ・公開には別途承認が必要。
