# 架空JSON専用の点数帯プレビュー

2026-10-20。score-preview.html と app-score-preview.js は通常アプリのindex.htmlから読み込まない独立ページ。架空740作品の固定JSONファイルだけ受け付ける。作品ID `fixture-####`、タイトル `架空作品 n`、740件、順位IDの形式を検査する。本番作品や本番保存データを読み込まないための制限であり、未知の第三者ファイルを一般に安全に変換する機能ではない。

ファイルの元テキストを保持して「変換前JSON」を同じ文字列としてダウンロードする。別の「変換候補JSON」には `fictional-score-preview-only` の種別を付ける。点数変更件数、順位全体の順番、星、レビュー・履歴・ジャンル等の扱いを画面に表示する。両方ともブラウザ内のBlobとして出力し、localStorage、IndexedDB、現在のアプリstate、外部通信、同期を使わない。stageのactivated:falseを維持し、移行確定は行わない。

隔離Chromeで架空740作品のファイルを読み込み、実際の両ダウンロードを読み戻して元文字列とplan出力に一致することを確認。元の未知フィールド・レビュー等は候補で維持。保存領域不変、アプリstate不在、外部通信なし、本番風のタイトルを含むJSONの拒否も確認。実機Safari、実データ、全回帰は未検証。

次はAstraで、固定JSONを実データ移行へ昇格させる際の復旧・比較手順、別端末/旧版の後日編集、独立保存先・同期先をレビューする。現段階のプレビュー出力を本番アプリに復元しない。
