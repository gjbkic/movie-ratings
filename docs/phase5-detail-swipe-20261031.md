# 詳細シートの下フリック調整（Draft候補のみ）

架空iPhone検証版v8で、映画詳細が本番版より閉じにくいとの実機報告を受けた。コード比較では、本番版も詳細上部のバーから下スワイプで閉じられるが、Draft候補はシート内を少しスクロールした状態で閉じるための距離・速度条件を追加していた。その条件が短い意図的な下フリックを取りこぼし、上部バーの閉じるボタン上から始めるスワイプも除外していた。

Draft候補だけで、スクロール後の下半分からの速いフリックを65px・0.55px/ms超、ゆっくりした長い操作を140px以上で閉じるよう調整した。上部バー内なら閉じるボタン上から始めたスワイプも扱う。入力欄等からのスワイプ除外、通常の遅い閲覧スクロール、背面スクロール防止は維持した。映画state・保存形式は変更していない。

`sheet-data-ui.cjs` に短い速い下フリックと閉じるボタン上からの操作を失敗先行で追加し、修正後8/8成功。Chromeの合成TouchEventはiPhone Safariの実指操作や慣性を再現しない。所有者限定の架空版で再確認し、意図しない閉鎖があれば閾値を再調整する。

ランキングの指スワイプについて、隔離Chromeで同一の架空740作品を使い本番コードと候補を比較した。単発のwheel操作は両者とも1400px移動・scrollイベント1回であり、iPhoneの慣性差の根拠にはならない。ランキングの大きなDOMとsticky表示を変更する前に実機の症状を切り分ける。今回の詳細修正を、ランキングの慣性改善が完了したものとは扱わない。
