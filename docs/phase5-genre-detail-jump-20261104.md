# ジャンル絞込から全体順位へ移動する導線

ジャンル絞込中に作品をタップすると、従来どおり詳細が開く。順位を交換する場合は、詳細内の「全体順位へ移動して入れ替える」を押す。ボタンを順位表示の直下に移した。絞込がない場合の表示は「全体順位の位置へ」のまま。

ボタンは既存の `jumpGlobal` を呼び、検索・絞込を解除して同じ作品を全体ランキングの位置に表示する。詳細を開くだけでは順位を変更しない。全体へ移動した後の↑↓は保存済みの同点内順位で隣り合う作品を交換する。以前の絞込条件へ戻る操作も残す。

`genre-detail-jump` は架空740作品で、絞込中に隠れている作品が全体順位で隣にある場合を選ぶ。詳細ボタンの表示位置と文言、ジャンプ前の順位不変、全体の隣との交換、ほかの点数帯・点数・星・レビュー・ジャンル・作品情報の不変、再読み込み後の順位を確認する。修正前は文言の検査で失敗した。絞込表示のまま↑↓する既存の `filtered-ui` テストも維持する。

本番の実データは触らない。iPhone Safariでのタップ位置・見え方は検証サイトで別途確認する。
