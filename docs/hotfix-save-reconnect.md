# 本番保存の接続復旧ホットフィックス

基準: main 279955d2d895fe48d401c4d2d795aa7c46da9aa5。未公開PRの変更を含めない。実データ・同期JSONは変更しない。

申告: iPhone本番で共通保存警告。ユーザーJSONを非公開ローカルへ退避。表示対象767作品/採点755作品と順位755件が対応、重複/点数不一致なし（歴史的に非表示にする1作品を除外）。このJSONだけから端末のストレージ例外までは判定できない。

再現した確実な不具合: localStorage書込み不可とIDB接続切断が重なると、openMovie30Dbが閉じた接続を恒久キャッシュし、再保存が失敗し続ける。初回open失敗のnullも恒久キャッシュしていた。ユーザー端末で同じ経路だったかは未確認。

修正: 接続close/versionchangeでキャッシュ無効化、open失敗後は次回再接続、閉じた接続/一時的接続例外時のみ再接続を一度試す。QuotaExceededErrorで再試行ループせずfalseを返す。current/previousを同じIDBトランザクションで書く形式は維持。既存データ/バックアップを削除・圧縮・初期化しない。

警告に元の保存停止理由とIDBエラー名を表示し、現在メモリ上の編集を保存する再試行ボタンを提供。順位安全ガードは迂回しない。JSON退避機能を維持。Web更新用にapp-core.jsキャッシュ識別子だけ変更。

再現テストは修正前falseで失敗、修正後true/再読み込み後レビュー保持/順位不変で成功。初回open一時失敗からの復帰も確認。通常の全回帰と既知問題再現を別に集計する。実機iPhoneの修復完了はユーザーの更新後保存/再起動確認をもって判定する。

追加保護：既存IDBの読込が失敗した場合は、接続し直しても未知の保存内容を上書きしない。正常読込までIDB書込みを保護停止し、最新JSON退避と再読み込みを案内。既存レコードが変わらない回帰を追加。
